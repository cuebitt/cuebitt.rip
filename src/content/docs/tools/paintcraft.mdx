## Description

Paintcraft is a web-based converter for [Xerca's Joy of Painting](https://modrinth.com/mod/joy-of-painting) mod for Minecraft.

You can use Paintcraft to resize, crop, downscale, quantize, and export images to `.paint` files.

Paintcraft supports the following versions of Joy of Painting:

- 1.x
- 2.x (glass canvas)
- Cobblemon Delta (custom canvas sizes)

## Usage

Visit [Paintcraft](https://cuebitt.github.io/paintcraft) in a web browser to get started.

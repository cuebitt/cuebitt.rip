## Description

Unity's [Splines](https://docs.unity3d.com/Packages/com.unity.splines@2.6/manual/index.html) package is handy for making bezier-curve based animations, prefab arrangements, and extruded meshes. Unfortunately, it's not supported by VRChat ([yet](https://feedback.vrchat.com/udon/p/expose-spline-components-for-world-creation)).

This package, VRCUnitySplines, allows you to use Unity's Splines in a VRChat world. You can create a spline using Unity's Splines editor, then "bake" the spline to an AnimationClip, VRCTween-based animation, or Udon-based animator.

### Features

- Unity Splines baking to AnimationClip, VRCTween, or Udon
- Unity Splines components are scrubbed from your scene on upload or play mode

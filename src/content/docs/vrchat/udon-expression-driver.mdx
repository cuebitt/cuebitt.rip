## Description

Udon Expression Driver (UED) is a set of tools and runtime scripts for porting VRChat avatar props to Worlds without modifying them. Props that use Dynamics (Physbones and Contacts) keep working, and UED adds VRCFury-style Armature Link and Full Controller components, so a prop can stick to a chosen humanoid bone on the player wearing it. It also provides world-space emulated expressions menus driven by the prop's own data.
